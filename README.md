# ستوديو الألوان: نموذج مبدئي لمعرض خدمات السيارات

نموذج عرض (Prototype) لمناقشة الفكرة مع صاحب المعرض قبل البناء الفعلي. يعمل بالكامل في المتصفح، بدون خادم.

## التشغيل
```bash
cd car-studio
python3 -m http.server 8080      # أو: npx serve .
# ثم افتح http://localhost:8080
```
يجب فتحه عبر خادم محلي (وليس بالضغط المزدوج على index.html) لأن النماذج ثلاثية الأبعاد تُحمَّل كملفات.

## الحسابات التجريبية
| الحساب | الدخول |
|---|---|
| العميل: محمد العتيبي | زر "دخول كعميل" في الصفحة الرئيسية، أو رقم 0551234567 |
| مالك المعرض | زر "دخول كمالك المعرض"، أو الرمز 1234 |

زر "عرض كمالك / عرض كعميل" أعلى الصفحة يبدّل بين الحسابين مباشرة أثناء التصوير.
"الإعدادات ← إعادة بيانات العرض التجريبي" يرجع كل شيء كما كان قبل إعادة التصوير.

## سيناريو مقترح لتصوير الفيديو (حوالي 3 دقائق)
1. **الرئيسية**: السيارة تدور وتتغير ألوانها الرسمية تلقائيًا، ثم الخدمات وخطوات العمل.
2. **المعرض**: افتح Ferrari 458 Spider، دوّرها، واضغط "من الداخل".
3. **دخول كمالك**: يفتح الاستوديو ثلاثي الأبعاد مباشرة؛ لف السيارة، غيّر اللون والتشطيب والفرش، وبدّل السيارة من القائمة.
4. **عرض كعميل** ← "احجز خدمة": اختر "تغيير لون الفرش" + "غسيل"، اختر موعدًا، ادفع بالبطاقة التجريبية.
4. **طلباتي** ← الطلب #1001: تصميم أرسله المعرض (أزرق بوتسي + ستيرنج أحمر). جرّب "من الداخل" ثم "أوافق على التصميم" وادفع المتبقي.
5. **عرض كمالك** ← لوحة الطلبات: المؤشرات والفلاتر.
6. افتح الطلب #1003 (Lamborghini Urus): غيّر لون الهيكل والتشطيب (مطفي/لؤلؤي)، ثم الجنوط، واكتب السعر، ثم "إرسال التصميم للعميل".
7. **عرض كعميل** ← الطلب #1003: التصميم وصل باللقطات والنموذج ثلاثي الأبعاد.
8. افتح الطلب الجديد الذي حجزته في الخطوة 3 كمالك، وصمّم الفرش من الداخل (كونياك، بيج…).
9. **السيارات** ← إضافة سيارة: رفع ملف GLB، الألوان الرسمية، وصور حقيقية لكل لون.
10. **المقترحات**: ما في النموذج، والمقترحات للمرحلة القادمة، وما يحتاجه البناء الفعلي.

## الموجود
- حجز بالمواعيد المتاحة وسعة لكل موعد، ودفع تجريبي (بطاقة / Apple Pay / في المعرض) مع التحقق من رقم البطاقة.
- الغسيل يُدفع كاملًا؛ خدمات التلوين بعربون، ثم يحدد المالك السعر في عرض التصميم، والعميل يدفع المتبقي بعد الموافقة.
- استوديو 3D للمالك فقط: الهيكل، الفرش، الستيرنج، الجنوط، الأرضية، مع التشطيبات (لامع، ميتاليك، لؤلؤي، ساتان، مطفي، جلد، نابا، شمواه).
- إرسال التصميم للعميل مع لقطات تلقائية من 3 زوايا، ثم موافقة أو طلب تعديل.
- إدارة السيارات (GLB + ألوان رسمية + صور حقيقية لكل لون)، الخدمات والأسعار، المواعيد، الإعدادات.
- ربط قطع أي نموذج جديد بالأجزاء القابلة للتلوين بالضغط عليها داخل الاستوديو.

## حدود النموذج
- البيانات محفوظة في متصفح الجهاز فقط (localStorage وIndexedDB). العميل والمالك يجب أن يكونا على نفس المتصفح للتجربة.
- الدفع شكلي: لا يتم أي خصم.
- الصور الحقيقية لكل لون يرفعها المعرض؛ صور البطاقات الحالية لقطات من النماذج ثلاثية الأبعاد.
